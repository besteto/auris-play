## How it was taken

`node` is not installed and none is wanted — the harness pages are the test suite
and they run in a real browser engine. `tools/harness.sh` drives headless Chrome
over `file://` and prints the `<pre id="out">` block, so the same pages a person
opens by hand also run from a terminal:

```bash
tools/harness.sh              # tests + smoke
tools/harness.sh tuning       # one page
```

It exits non-zero when any assertion fails, so it works as a gate.
