## Decision

**`PIECES_PER_SET` stays 3.**

This gives a three-set demo run of about 40 seconds (3 sets × 13.5 seconds), which reads as a natural wait for a client in a piercing studio. The baseline pre-work measured 3.43 drags per finished piece; the rebuilt game measures 3.29 — the tuning encoded in `START_PIECES` and `SPAWN_BIAS` survived the restructuring from collections to sets intact, and no adjustment is needed.

The measured median for three-tier sets at N=3 was **13.5 seconds per set**, which falls exactly in the expected band and validates the game's playability.

## How the Measurement Was Taken

The harness plays the way a person does: take a merge if one is on the tray, otherwise reach into the pouch, and unjam if neither is possible. The `smoke.html` test ran 100 seeds with 6 set retirements each, measuring the drag count between each retirement and converting to seconds.

- Median seconds per set: **13.5s** (three-tier)
- Demo run (3 sets): **40.5s**
- Pouch taps: 0.0 per run (the board never runs out of space)
- Unjams: 0.00 per run (the anti-jam rule was never needed)

All measurements assume the established `SEC_PER_DRAG = 1.35` constant, which relates to typical player drag timing.
