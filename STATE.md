## Действующие законы

- `ref-35` заморожен: один коммит, доставленный подарок [Р-001]. **Скриншоты с
  `besteto.github.io/ref-35/` — не эта ветка.** Там до сих пор ухо, «/ 35» и Birthday
  Edition; в `kiosk` ничего этого нет.
- **Носитель определяется флагом, никогда не догадкой** [Р-028]. По умолчанию телефон,
  киоск — по `#kiosk` в адресе. Ни ширина экрана, ни касание, ни user agent.
- Сброс по простою и аттракт-луп существуют только на киоске. На личном телефоне сброс
  по простою — не отсутствующая возможность, а дефект, стирающий чужой заход [Р-028].
- QR рисуется только на чужом экране, один за раз, `min(72vw, 60vh, 420px)` [Р-029].
- `src/rules.js` и `src/manifest.js` **чистые**: без DOM, без импортов. На этом стоит
  харнесс, который бьёт по ним напрямую.
- **`START_PIECES = 10`, `SPAWN_BIAS = 0.65`, поднос `min(94vw, 60vh, 440px)` не
  трогать.** Тюнинг измерен под эту геометрию [Р-014, Р-021, Р-030].
- На подносе всегда ровно три сета, пока заход идёт [Р-014].
- `relieve()` безусловен, в нормальной игре недостижим [Р-026].
- `state.done` — множество различных ключей, не журнал [Р-025].
- `src/game.js` — единственный файл, трогающий DOM.
- Всё называемое приходит из манифеста в рантайме [Р-010, Р-023].
- `PROMO_Auris/` и `choosed/` не коммитятся никогда.
- Никакого личного слоя под именем Auris [Р-007].
- Игра ничего не измеряет о человеке — на телефоне ровно так же, как на планшете.

## Последние решения

- Р-025 — `state.done` множество, а не журнал; ретайры по событиям
- Р-026 — `relieve` недостижим в игре; утверждается принцип Дирихле
- Р-027 — гейт из терминала: `tools/harness.sh`, `tools/pagecheck.sh`
- Р-028 — **носитель по флагу**: телефон по умолчанию, киоск по `#kiosk`
- Р-029 — **QR только на чужом экране**, один за раз, во всю плиту
- Р-030 — микротипографика на `clamp()`, игра не трогается
