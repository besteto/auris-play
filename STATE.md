## Действующие законы

- `ref-35` заморожен: один коммит, доставленный подарок [Р-001].
- `src/rules.js` и `src/manifest.js` **чистые**: без DOM, без импортов, только свой
  экспорт. На этом стоит весь харнесс, который бьёт по ним напрямую.
- **`START_PIECES = 10` и `SPAWN_BIAS = 0.65` не трогать.** Измерены под ровно три
  цепочки на 25 клетках; переход от коллекций к сетам они пережили (3.43 → 3.29 драга
  на готовую фишку) [Р-014, Р-021].
- На подносе всегда ровно три сета, пока заход идёт. Демо с исчерпанной очередью может
  сжаться — это терминальное состояние, не нарушение [Р-014].
- `relieve()` безусловен. В нормальной игре недостижим, и утверждается именно это
  [Р-026].
- `state.done` — множество различных ключей, не журнал. Ретайры считать по событиям
  `setComplete` [Р-025].
- `src/game.js` — единственный файл, трогающий DOM.
- Всё называемое (имена, акценты, пути спрайтов) приходит из манифеста в рантайме.
  Добавить коллекцию = строка и арт, без правки кода [Р-010, Р-023].
- `PROMO_Auris/` и `choosed/` не коммитятся никогда. 311 МБ из истории не вынимаются.
- Никакого личного слоя под именем Auris [Р-007].
- Киоск ничего не измеряет о человеке. Счётчик на стороне Auris допустим, если адрес
  постоянен для коллекции и короток [Р-020].

## Последние решения

- Р-021 — `PIECES_PER_SET = 3` подтверждён замером: 13.5 с на сет, ~40 с на демо
- Р-022 — четырёхтировые сеты 25.7 с на сет, с трёхтировыми на одном подносе не мешать
- Р-023 — акценты коллекций: оригинальные `#8e1f22` / `#2c4470` / `#b9705e`
- Р-024 — плиты 4:5, герой с другой съёмки; Маркеза не может быть выделенной в демо
- Р-025 — `state.done` множество, а не журнал; ретайры по событиям
- Р-026 — `relieve` недостижим в игре; утверждается принцип Дирихле, не сам вызов
- Р-027 — у проекта есть гейт из терминала: `tools/harness.sh`, `tools/pagecheck.sh`
