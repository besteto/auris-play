## Действующие законы

- `ref-35` заморожен: один коммит, доставленный подарок [Р-001]. Скриншоты с
  `besteto.github.io/ref-35/` — не эта игра.
- **Носитель определяется флагом, никогда не догадкой** [Р-028]. По умолчанию телефон,
  киоск — по `#kiosk`. Сброс по простою и аттракт-луп — только на киоске; сегодня их
  нет в коде вовсе.
- QR рисуется только на чужом экране, один за раз, `min(72vw, 60vh, 420px)` [Р-029].
- `src/rules.js` и `src/manifest.js` **чистые**: без DOM, без импортов.
- **`START_PIECES = 10`, `SPAWN_BIAS = 0.65`, поднос `min(94vw, 60vh, 440px)` не
  трогать** [Р-014, Р-021, Р-030].
- На подносе всегда ровно три сета, пока заход идёт [Р-014].
- `relieve()` безусловен, в нормальной игре недостижим [Р-026].
- Конец демо — плита коллекции в тот же тик, что и последний ретайр [Р-032].
- `state.done` — множество различных ключей, не журнал [Р-025].
- `src/game.js` — единственный файл, трогающий DOM.
- Всё называемое приходит из манифеста в рантайме [Р-010, Р-023]; статичная копия —
  из `data/copy.js`, по `data-i18n`, `data-i18n-aria`, `data-i18n-alt`.
- По-английски «витрина» — `showcase`; `tray` — только поднос, игровая сетка.
- Коммиты в формате `CONTRIBUTING.md`: `[Category] [symbol] описание`, одна строка,
  трейлер модели через пустую строку, без session URL.
- `PROMO_Auris/`, `choosed/`, `info_brief.md` не коммитятся никогда.
- Никакого личного слоя под именем Auris [Р-007].
- Игра ничего не измеряет о человеке.
